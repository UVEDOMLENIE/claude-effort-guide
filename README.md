## Быстрый выбор: задача → связка

| Задача | Возьми | Расход |
|---|---|---|
| Много одинаковых мелких дел: подписать 500 фото, разложить 1000 писем | **Haiku 4.5** | ×1 |
| Чат, поиск, мелкая правка | **Sonnet 5 low** | ×2 |
| Проверить, что сделала дешёвая модель; спорные случаи | **Opus 5 low** | ×2.5 |
| Одна программа или документ целиком; не знаешь, что выбрать | **Opus 5 high** | ×10 |
| Долгая задача: переделать большую программу, найти сложную ошибку | **Opus 5 extra** | ×15 |
| Исследование: прочитать много, сравнить, сделать вывод | **Fable 5.1 low** | ×6 |
| Спроектировать сложную систему, большой документ | **Fable 5.1 high** | ×12 |
| Проверить весь проект или 30 источников сразу | **Opus 5 extra** и слова «запусти агентов» | ×15 и выше |

## Шесть правил

1. **Не знаешь — Opus 5 high.**
2. **Мелочь — Haiku. Одно большое — Opus 5 high. Очень сложное — Fable 5.1 high.**
3. **Sonnet — только для мелочи.** Для большого Opus 5 low дешевле и умнее.
4. **Дёшево сначала, дорого на провалах.** Гони на low, провалы — на high.
5. **Max — только если extra не справился.**
6. **Ultracode — это extra плюс бригада за твой счёт.** Включай только чтобы проверить всё сразу.
